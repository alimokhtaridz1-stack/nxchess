# NXChess — Project Overview

## Vision

NXChess is a modern chess brand platform that combines **chess coaching**, **chess products**, and **future digital chess services** into a single unified experience. The goal is to become a premium chess destination where players of all levels can learn, shop, and eventually access AI-powered tools.

## Mission

Build a clean, scalable, and professional platform that grows from a marketing website (V1) into a full-featured chess ecosystem (V3).

---

## Goals

### Brand Goals
- Establish NXChess as a recognizable chess brand
- Create a premium, modern online presence
- Position for future digital chess services

### Technical Goals
- Build a fast, SEO-optimized website
- Use a scalable architecture that supports future features
- Enable multiple AI agents to collaborate on development
- Deploy on Vercel for global edge performance

---

## Current Version: V1

**Focus**: Static marketing website with 4 core pages.

| Page | Purpose |
|------|---------|
| Home | Brand introduction, hero section, highlights |
| Coaching | Chess coaching services, instructor profiles |
| Shop | Product showcase (static catalog for now) |
| Contact | Contact form, social links, location |

### V1 Constraints
- No database (all content is static/hardcoded)
- No authentication
- No payment processing
- No admin dashboard

---

## Future Roadmap

### Version 2 — Dynamic Platform
- Supabase integration (product database, content management)
- Admin dashboard for content/product management
- Coaching booking system with calendar
- Payment integration (Stripe)

### Version 3 — Chess Ecosystem
- Student accounts and progress tracking
- AI chess assistant (analysis, training)
- Online video courses platform
- Community features (forums, leaderboards)
